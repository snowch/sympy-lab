# SymPy Lab

[Start the course](https://snowch.github.io/sympy-lab/) · [Maths map & field notes](https://snowch.github.io/sympy-lab/field-notes.html)

Symbolic mathematics, one experiment at a time. A guided path through **48 short lessons and four integrated workshops**, with real SymPy in your browser and an optional maths refresher in every lesson.

The core moves from exact expressions and domains through algebra, equations, functions, calculus, matrices and small models to numerical Python. Every investigation has a prediction, independent executable source, labelled typeset results, a worked result generated from that source, a change to try, a fresh transfer question, two hints, feedback and a stated limitation.

## Maths refreshers

Each refresher is closed by default and contains a short plain-language explanation, a typeset equation and a small worked example of the prerequisite idea. Opening state saves with the lesson draft. A prerequisite map points back to the relevant modules. The panels are local reminders, not a claim to replace a full mathematics textbook.

## Run and develop

```sh
npm ci
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m playwright install --with-deps chromium
npm run check
npm run dev
```

Open `http://localhost:5173/sympy-lab/`. The Pages-shaped path checks relative assets. `npm run check` executes all sources, builds worked records and mathematical markup, checks links, and drives the actual browser/Wasm learning workflow. GitHub Actions checks before deploying `main` to Pages.

- `src/course.json`: lessons, refreshers, transfer questions, hints and references.
- `python/`: complete independently executable examples; edit these as the source of worked output.
- `scripts/execute.py`: native text, expression LaTeX and figure generation from exact published source.
- `scripts/layout.mjs`, `scripts/notes.mjs`, `src/style.css`: course, panels, prerequisite map and readable light/dark interface.
- `src/app.js`, `src/worker.js`, `src/editor.mjs`: local editor, real Python, typesetting, recovery, drafts and exports.
- `tests/`: mathematical/reference checks and browser evidence.

Assign a dictionary called `results` in an example to identify labelled expressions for mathematical rendering. The normal print loop makes the downloaded script useful outside the site. The runtime uses SymPy’s actual LaTeX output; KaTeX typesets it. The static build also typesets every refresher and worked result, so reading works with JavaScript disabled. Generated C text is explicitly labelled as uncompiled source; the course makes no C execution or performance claim.

## Runtime and records

Self-hosted, pinned Pyodide 0.27.7, SymPy 1.13.3, mpmath 1.3.0, NumPy 2.0.2 and Matplotlib 3.8.4. The native reference environment uses the same SymPy/mpmath/NumPy with Matplotlib 3.9.4. Wheel hashes are checked during the build. KaTeX 0.16.22 and all fonts are local. The first run downloads a substantial runtime; full offline use is not provided.

Code runs on the learner’s device. There is no account, analytics or Python server. Arbitrary Python can still access browser-permitted network resources; parsing and lambdify are not safe boundaries for untrusted external expressions.

Notes, predictions, code, report fields, refresher state, quiz attempts and reading marks use localStorage. Overview progress export/import makes these portable. Reading marks do not indicate assessed mastery. Completed runs remain in page memory until exported. Run JSON preserves exact executed code, expression text/LaTeX, output, SVG figures and versions. Markdown report export includes the completed execution and current report fields; retain run JSON for figures.
